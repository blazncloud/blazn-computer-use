# Milestone 0 qualification

Milestone 0 establishes reproducible evidence before the fork changes runtime
behavior. Its deterministic runner is:

```bash
python3 qualification/run_m0.py
```

Reports are written to `artifacts/m0/<commit>/qualification.json`; supporting
evidence for the same run stays beside that file. `artifacts/` is intentionally
untracked so local runs cannot change the release candidate.

Hosted macOS CI proves source metadata, result/oracle validation, the local
browser fixture, capability inventory, build, unit tests, CLI startup, MCP
initialize/list/call, JSON-CLI parity, and release packaging. Provider API-key
variables are removed from the parity process and no external service is
required.

The self-hosted GUI workflow is an explicit evidence class. With
`live_background` enabled it runs the D4 background-control trial with
effect, foreground-app, and physical-cursor oracles; operators retain three
clean trial artifacts for the milestone baseline. The imported upstream
baseline contains three clean background trials but is explicitly not labeled
D4 because its evaluator did not record cursor position. A
hosted runner cannot substitute for Accessibility, Screen Recording, focus,
cursor, or independent desktop-effect evidence.

The M0 JSON-CLI parity gate uses the read-only `health_report` operation. The
live D2/D4 mutation paths remain in the self-hosted lane until Milestone 2
freezes the shared versioned mutation contract.
